# Prompt : Système de transition (TransitionScreen) + anneau flash — FleurirDesktop

Date : 02/09/2026
Projet : FleurirDekstop (Electron + React + react-router-dom v7)

> **OBJECTIF** : Remplacer le `ResultPanel` (panneau de verdict « collé » sous la
> réponse) par le **système de transition du mobile** : un `TransitionScreen`
> plein écran qui s'affiche à la place de la carte après une réponse, + l'**anneau
> vert/rouge** (flash de bordure) sur la carte suivante.
>
> **RÉFÉRENCE** :
> - `FleurirMobile/components/question/TransitionScreen.tsx`
> - `FleurirMobile/components/question/QuestionCardContainer.tsx` (anneau flash)
> - `FleurirMobile/app/session.tsx` (comment le flux est piloté)
> - `FleurirMobile/constants/colors.ts` (`colors.error`, `colors.primary`)

---

## Comportement visé (copié du mobile)

### 1. Avant réponse
- La carte affiche la question (texte révélé phrase par phrase) + le `AnswerPanel`
  une fois tout révélé.

### 2. À la réponse
- La carte **est remplacée** par le `TransitionScreen` (écran plein).
- Verdict :
  - **Correcte** → « Bon ! » en **vert**, **avance automatiquement** après ~500 ms.
  - **Incorrecte** → « Raté... » en **rouge**, affiche le **contexte** (`history`)
    sous le verdict, et c'est un **clic** qui avance (pas de timer).
- Indication « Touchez pour continuer » en bas.

### 3. À l'avancement
- La question suivante est chargée et la carte revient.
- Un **anneau** (bordure épaisse) **vert** (réponse correcte précédente) ou
  **rouge** (incorrecte) apparaît sur la carte et **fond par lui-même** (~700 ms).

### 4. Behaviour clé
- On **ne charge pas** la question suivante immédiatement à la réponse : on attend
  le tap (erreur) ou le timer (bonne réponse), comme sur le mobile.
- L'anneau est joué à l'arrivée de chaque **nouvelle** carte, coloré par le verdict
  de la question **précédente**.

---

## Architecture (adaptation au desktop)

Le desktop utilise une **pile implicite** via `useQuestion` (une seule question
chargée + `loadNext()`) et gardait `lastResult` pour coller le verdict. On remplace
ça par un **état de transition explicite** :

```ts
// Dans Session.tsx
const [transition, setTransition] = useState<{
  correct: boolean
  history: string
} | null>(null)
```

- `transition !== null` → on affiche le `TransitionScreen` à la place de la carte.
- `transition.correct === true` → `autoAdvanceMs = 500` ; sinon pas de timer.
- Le `onNext` du TransitionScreen → `setTransition(null)` + `loadNext()`.
- `lastCorrect` (verdict de la question précédente) est conservé pour l'anneau.

## Étape 1 — Créer `TransitionScreen.tsx`

```tsx
import { useEffect } from 'react'
import type { ReactNode } from 'react'

/**
 * Écran plein de transition entre deux questions (copié du mobile). S'affiche à
 * la place de la carte après une réponse :
 * - « Bon ! » (vert) si correct, « Raté... » (rouge) sinon ;
 * - le contexte de la question (question.history) en dessous UNIQUEMENT après
 *   une erreur, pour lecture ;
 * - bonne réponse : avance automatiquement après `autoAdvanceMs` ;
 * - erreur : pas de timer, c'est un clic qui passe à la question suivante.
 */
function TransitionScreen({
  correct,
  history,
  autoAdvanceMs,
  onNext
}: {
  correct: boolean
  history: string
  autoAdvanceMs?: number
  onNext: () => void
}): React.JSX.Element {
  useEffect(() => {
    if (autoAdvanceMs === undefined) return
    const timer = setTimeout(onNext, autoAdvanceMs)
    return () => clearTimeout(timer)
  }, [autoAdvanceMs, onNext])

  return (
    <div className="transition-screen" onClick={onNext}>
      <p className={`transition-verdict ${correct ? 'correct' : 'wrong'}`}>
        {correct ? 'Bon !' : 'Raté...'}
      </p>
      {!correct && history !== '' && (
        <p className="transition-history" spellCheck={false}>
          {history}
        </p>
      )}
      <p className="transition-hint">Touchez pour continuer</p>
    </div>
  )
}

export default TransitionScreen
```

**Note ReactNode** : si on veut le rendu LaTeX du `history` (comme le mobile via
`LatexText`), remplacer `<p className="transition-history">` par un `LatexText`.
Le desktop a déjà `LatexText` : import `from '../LatexText'` et l'utiliser pour le
contexte (`<LatexText className="transition-history">{history}</LatexText>`).
`ReactNode` import inutile dans ce cas — à retirer si non utilisé.

## Étape 2 — Créer `QuestionCardContainer.tsx` (anneau flash)

Wrapper qui ajoute l'**anneau borderé vert/rouge** au-dessus de la carte, et le
fait fondre (~700 ms) quand une nouvelle carte arrive.

```tsx
import { useEffect, useState } from 'react'
import type { ReactNode } from 'react'

/**
 * Conteneur animé de la carte courante : apporte l'anneau (flash de bordure)
 * vert/rouge au verdict de la question précédente, joué à chaque nouvelle carte.
 * La couleur suit `flash` ('success' | 'error'), la clé `flashKey` rejoue l'effet.
 */
function QuestionCardContainer({
  children,
  flash,
  flashKey
}: {
  children: ReactNode
  flash: 'success' | 'error' | null
  flashKey: number
}): React.JSX.Element {
  const [visible, setVisible] = useState(true)
  const [fading, setFading] = useState(false)

  // À chaque nouvelle carte (flashKey change) : on repart opaque puis on fond.
  useEffect(() => {
    if (flash === null) return
    setVisible(true)
    setFading(true)
    const timer = setTimeout(() => setFading(false), 700)
    return () => clearTimeout(timer)
  }, [flash, flashKey])

  const color =
    flash === 'success' ? 'var(--green-40)' : flash === 'error' ? 'var(--error)' : undefined

  return (
    <div className="question-card-stage">
      <div className="question-card-wrap">{children}</div>
      {flash !== null && (
        <div
          className={`flash-ring ${fading ? 'fading' : ''}`}
          style={{ borderColor: color }}
          aria-hidden="true"
        />
      )}
    </div>
  )
}

export default QuestionCardContainer
```

**Note CSS de l'anneau** : `--error` n'existe pas — utiliser la couleur d'erreur du
desktop (`#ff6b6b` ou `var(--md-sys-color-error)`). Voir étape 5.

### 3c. `handleAnswer`
```ts
const handleAnswer = async (value: string): Promise<void> => {
  answerQuestion(value)
  if (question !== null) {
    const expected = expectedAnswer(question.answer)
    const correct = isAnswerCorrect(expected, value, containsLatex(expected, value))
    setLastCorrect(correct)
    // On NE charge PAS la suivante ici : on passe en transition.
    setTransition({ correct, history: question.history })
    try {
      await submitAnswer(question.id, correct)
    } catch {
      // La réponse reste enregistrée localement
    }
  }
}
```

### 3d. `handleNext`
```ts
const handleNext = (): void => {
  setTransition(null)
  loadNext()
}
```

### 3e. Rendu (zone carte)
- Si `transition !== null` → `TransitionScreen`.
- Sinon, si question chargée → carte dans `QuestionCardContainer` + AnswerPanel.
- L'anneau est piloté par `lastCorrect` (verdict de la question précédente), rejoué
  par `sessionKey` (nouvelle question) :

```tsx
{question !== null && transition === null && (
  <div className="question-session">
    <QuestionToolbar question={question} />
    <QuestionCardContainer flash={flash} flashKey={sessionKey ?? 0}>
      <QuestionCard sentences={sentences} visible={visible} />
    </QuestionCardContainer>
    {visible >= sentences.length && (
      <AnswerPanel
        question={question}
        sessionKey={sessionKey}
        disabled={selectedAnswer !== null}
        onAnswer={handleAnswer}
        inputRef={inputRef}
      />
    )}
  </div>
)}

{transition !== null && (
  <TransitionScreen
    correct={transition.correct}
    history={transition.history}
    autoAdvanceMs={transition.correct ? 500 : undefined}
    onNext={handleNext}
  />
)}
```

```ts

  lastCorrect === null ? null : lastCorrect ? 'success' : 'error'
```
